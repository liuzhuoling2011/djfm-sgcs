# 刀剑封魔录外传：上古传说 — Web Remake

浏览器可玩的《刀剑封魔录外传：上古传说》静态网页重制版（进行中 / WIP）。

A static web remake of *Blade and Sword 2: Ancient Legend* (work in progress).

## 在线试玩 / Play

GitHub Pages: https://liuzhuoling2011.github.io/djfm-sgcs/

## 操作 / Controls

| 键 / Key | 作用 / Action |
|----------|---------------|
| WASD / 方向键 | 移动 / Move |
| E | 对话 / Talk |
| Space | 攻击 / Attack |

## 说明 / Notes

- 纯静态站点，不包含原版游戏可执行文件。
- Static site only; the original game executable is **not** included.
- 地图、建筑、HUD 等仍在对照原版继续修正。
- Map placement, buildings, HUD, combat, etc. are still being aligned with the original.

## 本地打开 / Local

用任意静态服务器打开本目录，例如：

```bash
npx serve .
# or: python3 -m http.server 8080
```

然后访问提示的本地地址。
